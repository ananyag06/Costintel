QUICK START
================================================================================

1. Prerequisites
   - Python 3.9+
   - Node.js 18+
   - PostgreSQL 12+
   - xAI API key
   - Firebase config

2. Backend Setup
   cd backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   # Edit .env with your keys
   python -m uvicorn app.main:app --reload

3. Frontend Setup
   cd frontend
   npm install
   npm run dev

4. Access
   Frontend: http://localhost:5173
   Backend: http://localhost:8000
   API Docs: http://localhost:8000/docs

For detailed instructions, see QUICKSTART.md or FINAL_DELIVERABLES.md

TROUBLESHOOTING GUIDE
================================================================================

Issue: "react-router-dom" dependency missing
Solution: Already fixed! App.tsx now uses state-based routing.

Issue: API not responding
Solution: 
  1. Check backend is running: ps aux | grep uvicorn
  2. Check port: lsof -i :8000
  3. Check logs: tail -f backend.log

Issue: Insights not generating
Solution:
  1. Verify XAI_API_KEY is set: echo $XAI_API_KEY
  2. Check database: SELECT COUNT(*) FROM diagnostic_insights;
  3. Check logs: grep -i "insight" backend.log

Issue: Frontend shows blank screen
Solution:
  1. Check browser console (F12)
  2. Verify VITE_API_URL is correct
  3. Clear browser cache and reload

For more troubleshooting, see FINAL_DELIVERABLES.md
